# Module Mobile App (Flutter)

> Module này sẽ được phát triển với Dart/Flutter.

## Tính năng
- Live Stream với ROI overlay
- Interactive polygon drawing (vẽ vùng nguy hiểm)
- Alert Dashboard (HITL - Human-in-the-loop)
- Push notification với snapshot + video clip

## Setup
```bash
flutter create module_mobile_app
cd module_mobile_app
flutter pub get
```

## Tech Stack
- Flutter 3.x
- Dart
- WebRTC (live streaming)
- Firebase Cloud Messaging (push notification)
